# Article Sentiment Analysis

A Python project that crawls web articles, cleans the text, and performs sentiment analysis using **TextBlob** to classify content as positive, negative, or neutral.

---

## Features
- Scrapes and preprocesses article text from given URLs  
- Tokenizes and analyzes sentiment using NLP techniques  
- Provides polarity & subjectivity scores with insights  

---

## Tools & Libraries
- Python, TextBlob  
- Requests, BeautifulSoup
